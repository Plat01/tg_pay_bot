# План: Fix HTML parsing error in profile handler

## Проблема

Ошибка `TelegramBadRequest: can't parse entities: Unsupported start tag "sкала" at byte offset 73` возникает в `handle_profile_callback` (start.py:199).

Причина: в имени пользователя (`display_name`) содержится символ `<`, который Telegram интерпретирует как начало HTML-тега при `parse_mode="HTML"`. В тексте `PROFILE_NO_SUBSCRIPTION` переменная `{username}` не экранируется, что приводит к ошибке парсинга.

## Решение

1. Добавить функцию для экранирования HTML-специальных символов
2. Экранировать `display_name` перед использованием в сообщениях с `parse_mode="HTML"`

## Изменения

### Файл: `src/bot/handlers/start.py`

Добавить импорт `html` и экранировать `display_name` в функции `handle_profile_callback`:

```python
import html  # Добавить в импорты

# В handle_profile_callback (строка ~165):
display_name = " ".join(name_parts) if name_parts else (user.username or f"#{user.id}")
display_name = html.escape(display_name)  # Экранировать HTML-символы
```
