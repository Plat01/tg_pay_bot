## Риски и решения

### Риск 1: Активные подписки без VPN links
**Решение:** Ленивая миграция - при запросе VPN link создаем encrypted_subscription через API, если еще нет

### Риск 2: Trial subscriptions без subscription_id
**Решение:** EncryptedSubscription.subscription_id nullable, trial создает standalone encrypted_subscription

### Риск 3: API sub-oval.online недоступен
**Решение:** Graceful error handling, retry logic, fallback message для пользователя

### Риск 4: TTL hours calculation
**Решение:** Map tariff_type -> duration_days -> ttl_hours:
- trial: 3 days = 72 hours
- monthly: 30 days = 720 hours
- quarterly: 90 days = 2160 hours
- yearly: 365 days = 8760 hours
