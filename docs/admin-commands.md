# Админские команды

Команды доступны только пользователям из `ADMIN_ID_LIST` в `.env`.

## Просмотр информации

| Команда | Описание |
|---------|----------|
| `/subscriptions` | Список всех пользователей с активными подписками |
| `/payments <telegram_id>` | Платежи пользователя по Telegram ID |
| `/payment_by_ext <external_id>` | Найти пользователя по id платежа |

Пример: `/payment_by_ext abc123xyz`

## Рассылки

| Команда | Описание |
|---------|----------|
| `/all_message` | Отправить сообщение всем пользователям |
| `/pay_message` | Отправить сообщение пользователям с платной подпиской |

После команды бот запросит сообщение. Можно отправить:
- **Текст** — текстовое сообщение с HTML-разметкой
- **Фото** — изображение с подписью (caption)
- **Видео** — видеофайл с подписью (caption)

Для отмены: `/cancel`.

## Управление балансом

### Интерактивный режим
```
/add_balance
```
Бот запросит: Telegram ID → сумма → сообщение → подтверждение.

### Быстрый режим
```
/add_balance <telegram_id> <сумма>
```
Пример: `/add_balance 123456789 500`

## Выдача подписок

### Интерактивный режим
```
/grant_subscription
```
Бот запросит: Telegram ID → количество дней → подтверждение.

### Быстрый режим
```
/grant_subscription <telegram_id> <дней>
```
Количество дней определяет тип подписки:
• меньше 4 = trial (3 дня)
• 4-29 = monthly (30 дней)
• 30-89 = quarterly (90 дней)
• 90+ = yearly (365 дней)

Пример: `/grant_subscription 123456789 30`

## Отмена

| Команда | Описание |
|---------|----------|
| `/cancel` | Отменить текущий процесс (рассылка, начисление, выдача подписки) |
