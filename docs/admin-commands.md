# Админские команды

Команды доступны только пользователям из `ADMIN_ID_LIST` в `.env`.

## Просмотр информации

| Команда | Описание |
|---------|----------|
| `/subscriptions` | Список всех пользователей с активными подписками |
| `/payments <telegram_id>` | Платежи пользователя по Telegram ID |
| `/payment_by_ext <external_id>` | Найти пользователя по id платежа |

Пример: `/payment_by_ext abc123xyz`

## Рассылки

| Команда | Описание |
|---------|----------|
| `/all_message` | Отправить сообщение всем пользователям |
| `/pay_message` | Отправить сообщение пользователям с платной подпиской |

После команды бот запросит сообщение. Можно отправить:
- **Текст** — текстовое сообщение с HTML-разметкой
- **Фото** — изображение с подписью (caption)
- **Видео** — видеофайл с подписью (caption)

Для отмены: `/cancel`.

## Управление балансом

### Интерактивный режим
```
/add_balance
```
Бот запросит: Telegram ID → сумма → сообщение → подтверждение.

### Быстрый режим
```
/add_balance <telegram_id> <сумма>
```
Пример: `/add_balance 123456789 500`

## Выдача подписок

### Интерактивный режим
```
/grant_subscription
```
Бот запросит: Telegram ID → количество дней → подтверждение.

### Быстрый режим
```
/grant_subscription <telegram_id> <дней>
```
Количество дней определяет тип подписки (границы настраиваются в `/tariffs`, пункт 6):
• меньше 4 = trial (3 дня)
• 4-29 = monthly (30 дней)
• 30-89 = quarterly (90 дней)
• 90+ = yearly (365 дней)

Пример: `/grant_subscription 123456789 30`

## Управление тарифами

### Изменение тарифов
```
/tariffs
```
Бот покажет список тарифов и попросит номер тарифа, затем номер поля:

| № | Поле |
|---|------|
| 1 | Цена |
| 2 | Длительность (дней) |
| 3 | Количество устройств |
| 4 | Текст длительности (в кнопке: «1 месяц») |
| 5 | Название типа подписки («Месячная») |
| 6 | Макс. дней ручной выдачи (для `/grant_subscription`) |
| 7 | Включить / выключить тариф |
| 8 | Удалить тариф |

После ввода значения бот покажет, как изменится кнопка, и попросит подтверждение (да/нет).
Изменения применяются сразу, перезапуск бота не нужен.

### Новый тариф
```
/add_tariff
```
Бот спросит по шагам: код тарифа латиницей (например, `half_year`) → цена → длительность в днях →
количество устройств → текст длительности → название типа. Затем покажет превью кнопки и запросит
подтверждение. Новый тариф сразу появляется в меню оплаты, в списке он встаёт по длительности.

### Что нужно знать

- **Цены уникальны.** Бот не даст задать цену, которая уже занята другим тарифом: платежи без
  метаданных о тарифе определяются по сумме.
- Уже выставленные счета сохраняют свою сумму и тариф — пользователь получит то, что выбирал.
- Уже выданные подписки не меняются: у них своя дата окончания.
- Тариф `trial` удалить нельзя, только изменить или выключить.
- Если тариф просто больше не продаётся — выключите его (пункт 7): он исчезнет из меню оплаты,
  но названия в карточках подписок останутся.
- Символы `< > &` в текстах запрещены — они ломают разметку сообщений.

## Отмена

| Команда | Описание |
|---------|----------|
| `/cancel` | Отменить текущий процесс (рассылка, начисление, выдача подписки, изменение тарифов) |
